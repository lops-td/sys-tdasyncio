## Changes for this version

- Relicensed `sys-tdasyncio` under Apache License 2.0, with the official
  `LICENSE`, a `NOTICE`, manifest metadata, README terms, and source headers.
- Embedded the full Apache License and an Apache license notice inside the
  standalone TOX.
- Removed the `Clearall` parameter expression that referenced
  `op.LOP.par.Cancelallasync`; the pulse now calls the component's own
  `Clearall()` extension method and works without a LOPs host.
- Verified the exported TOX in TouchDesigner 2023.12370 and 2025.32820.
